## Workflow `.github/workflows/profile-widgets.yml`

- Disparadores: cron diario `0 6 * * *`, `workflow_dispatch`, push que cambie el workflow.
- Pasos:
  - `lowlighter/metrics@v3.34` × 4 → `metrics.base.svg`, `metrics.languages.svg`, `metrics.isocalendar.svg`, `metrics.activity.svg` (timezone `America/Montevideo`).
  - `Platane/snk@v3.5.0` → `github-snake.svg`, `github-snake-dark.svg`.
  - `crazy-max/ghaction-github-pages@v5.0.0` → publica todo en el branch `output`.
- Secret requerido: `METRICS_TOKEN` = PAT classic con scope `read:user` (agregar `repo` para incluir repos privados en las stats).

## Publicar

`gh` tiene dos cuentas; la activa es `daniel-face-auth`, que **no** tiene permisos sobre `danielfrascarelli`. Usar el token de `danielfrascarelli` solo para estos comandos:

    export GH_TOKEN=$(gh auth token -u danielfrascarelli)
    gh repo create danielfrascarelli/danielfrascarelli --public --source . --remote origin
    git -c credential.helper= -c 'credential.helper=!gh auth git-credential' push -u origin main
    gh secret set METRICS_TOKEN -R danielfrascarelli/danielfrascarelli   # pega el PAT
    gh workflow run profile-widgets.yml -R danielfrascarelli/danielfrascarelli

Alternativa permanente: `gh auth switch -u danielfrascarelli` (afecta a todos los repos).
